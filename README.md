# Certified Ethical Hacker Portfolio

A professional, hacker-themed portfolio website for George Louis Joseph.

## Overview
This project is a standalone HTML/CSS/JavaScript portfolio designed for a cybersecurity professional with a Certified Ethical Hacker focus.

## Files
- `index.html` – portfolio structure and content
- `styles.css` – hacker-themed dark neon styling
- `script.js` – simple footer year script

## Run locally
Open `index.html` in a browser.

Or serve it with a local HTTP server:

```bash
python3 -m http.server 8000
```

Then visit:

`http://localhost:8000`

## Customize
Update the content in `index.html` with your real:
- LinkedIn URL
- projects
- certifications
- experience details
- additional contact links
